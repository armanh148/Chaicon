# Chaicon Clone - B2B Sourcing Marketplace

Modern and professional B2B Wholesale Mandi portal cloned & redesigned from [Chaicon.com](https://www.chaicon.com/).

## Features
- **Authentic Brand Theme:** Chaicon signature Magenta (`#e61c83`), Warning Mustard Orange (`#f7931e`), and Deep Charcoal Navy (`#102a43`).
- **Interactive Search & Filtering:** Real-time city filters (Lahore, Karachi, Faisalabad, etc.) and keyword search.
- **Product Catalog:** High-conversion product cards with PKR/USD rates, MOQs, verified factory tags, and direct WhatsApp / RFQ action modals.
- **Responsive:** Mobile, tablet, and desktop friendly layout.

## Run Locally
Open `index.html` directly in your browser or run a local server:
```bash
npx serve -l 3001
```
